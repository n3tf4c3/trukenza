# Trukenza

Truco espanhol multiplayer numa mesa 3D, com os amigos. Jogo social, sem apostas.

```powershell
pnpm install
pnpm server   # mesas em ws://localhost:2580
pnpm web      # http://localhost:5180
```

Ou tudo em Docker: `docker compose up -d --build` e http://localhost:4180.

Guia do projeto: `AGENTS.md`. Arquitetura: `docs/arquitetura.md`. Regras: `docs/regras.md`. Docker e publicação: `docs/docker.md`.
